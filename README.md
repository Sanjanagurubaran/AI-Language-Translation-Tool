# AI Language Translator – Description
<img width="1888" height="903" alt="image" src="https://github.com/user-attachments/assets/8813eda7-15db-4d93-95a4-1a5e8286958a" />


The **AI Language Translator** is a smart web-based application that allows users to instantly translate text between multiple languages using AI-powered translation technology. The tool provides a clean and modern UI with additional features like speech recognition, text-to-speech, copy functionality, and language swapping for a better user experience.

## ✨ Features

* 🌍 Translate text between multiple languages
* 🎤 Speech-to-text input using microphone
* 🔊 Text-to-speech output for translated text
* 📋 Copy translated text instantly
* 🔄 Swap source and target languages
* ⚡ Fast real-time translation using Google Translate API
* 🎨 Modern responsive UI using HTML, CSS, and JavaScript

## 🌐 Supported Languages

* English
* Tamil
* Hindi
* French
* Telugu
* Malayalam

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Translate API
* Web Speech API
* Font Awesome Icons
* Google Fonts (Poppins)

## 📌 How It Works

1. User enters text or speaks using the microphone.
2. Selects source and target languages.
3. Clicks the Translate button.
4. The application fetches translated text using the translation API.
5. User can copy or listen to the translated output.

## 🎯 Purpose

This tool is designed to help users communicate easily across different languages, making translation faster, simpler, and more interactive. It is useful for students, travelers, developers, and multilingual communication.


The AI Language Translator is a web-based application that translates text between multiple languages instantly using AI-powered translation. It includes features like speech-to-text, text-to-speech, copy text, and language swap with a modern responsive UI built using HTML, CSS, and JavaScript.
